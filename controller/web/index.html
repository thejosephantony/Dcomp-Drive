APRESENTAÇÃO ACADÊMICA

Modo de demonstração

Falhas lógicas reais, recuperação automática e corrupção de uma única réplica de teste.

Acesso administrativo

Use apenas em laboratório isolado. O token permanece somente nesta página e não é salvo no navegador. Para executar ações, acesse por HTTPS ou localhost via SSH.

Este endereço não é seguro. Abra o dashboard via HTTPS ou http://localhost:8000/ por SSH.

1. Falha e recuperação de nó

O storage deixa de responder e de enviar heartbeats. O controlador detecta a falha e re-replica os objetos.

2. Detecção de corrupção

Altera um byte de uma réplica descartável e executa scrubbing real. O reparador recompõe as cópias.
